# KickLink

Private pickup-sports club management: clubs, games, payments, waitlists.

- **`web/`** — the app (Next.js, Postgres/Prisma, Auth.js, Stripe Connect).
  Setup, deployment and environment variables: [`web/README.md`](web/README.md).
- **`web/docs/`** — operations runbook, production-readiness audit, API notes, ADRs.
- **`docs/design/`** — the original design handoff (HTML prototypes, product
  and flow specs). Reference only; not built or deployed.
